# 4-Experimental-Modal-Analysis-of-a-Scaled-Bridge-Results-and-Mode-Shapes
This report documented the operational modal analysis of a scaled bridge (v2). It mapped accelerometer positions, computed and plotted the sum of auto-PSDs, and built a stabilization diagram to identify stable poles. A summary table reported the natural frequencies and damping ratios of the first three flexural modes.


What the report includes

Accelerometer layout — figure with exact sensor positions on the bridge.

Spectral content — figure of the sum of auto-PSDs across all channels.

Stabilization diagram — pole stabilization from system identification on one channel.

Modal table — natural frequencies and damping ratios for the first three flexural modes.

Mode shapes — figures of the 1st and 3rd flexural mode shapes.
